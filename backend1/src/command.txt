ПЕРЕВІРКА CRUD ОПЕРАЦІЙ USERS
curl -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d "{ \"name\": \"Test\" }"
curl http://localhost:3000/api/users
curl http://localhost:3000/api/users/1
curl -X PUT http://localhost:3000/api/users/1 -H "Content-Type: application/json" -d "{ \"name\": \"Updated test\" }"
curl -X DELETE http://localhost:3000/api/users/1
==============
ПЕРЕВІРКА CRUD ОПЕРАЦІЙ POSTS
curl -X POST http://localhost:3000/api/posts -H "Content-Type: application/json" -d "{ \"title\": \"First Post\", \"content\": \"Hello world\", \"userId\": 1 }"
curl http://localhost:3000/api/posts
curl http://localhost:3000/api/posts/1
curl -X PUT http://localhost:3000/api/posts/1 -H "Content-Type: application/json" -d "{ \"title\": \"Updated title\", \"content\": \"Updated content\" }"
curl -X DELETE http://localhost:3000/api/posts/1
==============

curl -X PUT http://localhost:3000/api/comments/1 -H "Content-Type: application/json" -d "{\"text\":\"updated comment\"}"

КОМАНДИ ДЛЯ ПЕРЕВІРКИ

JOIN - пости з авторами
curl http://localhost:3000/api/posts-with-authors

Агрегація - статистика постів
curl http://localhost:3000/api/stats/posts-per-user

LIKE пошук - нормальний
curl "http://localhost:3000/api/search/posts?q=First"

LIKE пошук - SQL injection демонстрація
curl "http://localhost:3000/api/search/posts?q=' OR '1'='1"

409 Conflict - дублікат email
curl -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d "{\"name\":\"Alice\",\"email\":\"alice@example.com\"}"
curl -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d "{\"name\":\"Alice2\",\"email\":\"alice@example.com\"}"

Мультитаблична операція
curl -X POST http://localhost:3000/api/users-with-post -H "Content-Type: application/json" -d "{\"name\":\"John\",\"email\":\"john@example.com\",\"title\":\"My Post\",\"content\":\"Hello!\"}"

Пагінація і сортування
curl "http://localhost:3000/api/users?page=1&limit=10&sortBy=name&order=asc"
curl "http://localhost:3000/api/posts?page=1&limit=10&sortBy=title&order=desc"

Фільтрація
curl "http://localhost:3000/api/posts?userId=1"	
curl "http://localhost:3000/api/comments?postId=1"

Логування DB подій
curl "http://localhost:3000/api/search/posts?q=First"
