Лабораторна робота №2 Перед початком роботи прочитайте README. 
Щоб все працювало коректно, потрібно виконати наступні пункти:
1. Створити в себе на пристрої папку з назвою backend.
2. З репозиторію завантажити всі файли з папки backend1 і перенести їх у вашу, щойно створену папку.
3. У вашій папці backend запустити термінал і прописати команду npm install (має з'явитися папка node_modules).
4. Потім у тому самому терміналі написати команду npm run dev і якщо буде написано Server running on port 3000, значить що все працює коректно.
5. Далі відкриваємо cmd і вписуємо команди з документу command.txt і перевіряємо на CRUD і якщо все працює коректно, то ви все зробили правильно!
