curl http://localhost:3000/api/v1/users
curl http://localhost:3000/api/v1/users/1
curl -X PUT http://localhost:3000/api/v1/users/1 -H "Content-Type: application/json" -d "{ \"name\": \"Updated test\" }"

ПЕРЕВІРКА ВАЛІДАЦІЇ ТА ПОМИЛОК
400 - порожнє тіло
curl -X POST http://localhost:3000/api/v1/users -H "Content-Type: application/json" -d "{}"
404 - не знайдено
curl http://localhost:3000/api/v1/users/99999
409 Conflict - дублікат email
curl -X POST http://localhost:3000/api/v1/users -H "Content-Type: application/json" -d "{\"name\":\"Alice\",\"email\":\"alice@example.com\"}"
curl -X POST http://localhost:3000/api/v1/users -H "Content-Type: application/json" -d "{\"name\":\"Alice2\",\"email\":\"alice@example.com\"}"

ПОШУК, ФІЛЬТРАЦІЯ, СОРТУВАННЯ
LIKE пошук - нормальний
curl "http://localhost:3000/api/v1/search/posts?q=First"
LIKE пошук - SQL injection демонстрація
curl "http://localhost:3000/api/v1/search/posts?q=%27%20OR%20%271%27%3D%271"
Пагінація і сортування
curl "http://localhost:3000/api/v1/users?page=1&limit=10&sortBy=name&order=asc"
curl "http://localhost:3000/api/v1/posts?page=1&limit=10&sortBy=title&order=desc"
Фільтрація
curl "http://localhost:3000/api/v1/posts?userId=1"
curl "http://localhost:3000/api/v1/comments?postId=1"
==============
